# sg200X-riscv64-linux-templates

This project/organization aims to create easy-to-use and hackable templates for sg200X MCU with embedded linux distros. It can be handy for the following boards: Milk-V Duo 256M/S/Module 01, LicheeRV Nano

## Available Templates

| Repository    | Available     | Description   |
| ------------- | ------------- | ------------- |
| [c-build-template](https://github.com/sg200X-riscv64-linux-templates/c-build-template)   | ✅            | cross-compiling C/C++ to RISC-V Linux Board              |
| [go-build-template](https://github.com/sg200X-riscv64-linux-templates/go-build-template) | ✅            | cross-compiling Go to RISC-V Linux Board|
| pytorch-to-cvitek-tpu | TODO           | pytorch trained models to cvitek tpu format trough ONNX|

## Contributing

Contributions are welcome! Feel free to open issues or pull requests on any of the repositories above.
